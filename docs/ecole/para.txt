D. Paramètres propres aux différents niveaux
- Primaire : stabilité de l'enseignant principal, alternance des activités, temps d'attention, activités d'éveil et de repos.
- Collège : rotation des matières, groupes de langues, travaux pratiques, équilibre entre disciplines.
- Lycée : filières, spécialités, options, préparation aux examens, mutualisation des enseignements.
- Écoles privées : groupes de formation, parcours personnalisés, cours intensifs, formations professionnelles.
- Universités : UE, ECUE, crédits ECTS ou système équivalent, parcours, semestres, groupes de TD, groupes de TP, cours magistraux mutualisés, enseignements inter-filières.

14. Paramètres liés aux préférences et à la qualité de vie
Ce sont des paramètres qui ne sont pas toujours obligatoires, mais qui améliorent considérablement la qualité du planning.
Pour les enseignants
- Réduire les trous entre les cours.
- Éviter les journées trop longues.
- Regrouper les cours sur certains jours.
- Limiter les déplacements.
- Respecter les préférences horaires.
- Éviter les cours trop tôt ou trop tard.
- Équilibrer les charges entre enseignants.
Pour les apprenants
- Réduire les journées excessivement chargées.
- Éviter les longues périodes sans cours.
- Éviter les cours tardifs.
- Répartir les matières difficiles.
- Préserver les activités sportives.
- Préserver les temps de repas.
- Éviter les déplacements inutiles.
- Éviter les conflits entre options.
- Préserver les temps de révision.
Pour l'administration
- Simplifier les changements de salles.
- Faciliter la surveillance.
- Réduire les conflits de ressources.
- Éviter les changements fréquents de planning.
- Faciliter le remplacement des enseignants.

18. La distinction fondamentale : contraintes obligatoires et préférences
C'est probablement la décision architecturale la plus importante pour ton générateur.

Il ne faut surtout pas traiter tous les paramètres de la même manière.

Je recommande de les diviser en deux grandes catégories.
A. Contraintes strictes (Hard Constraints)
Non négociables
Le moteur ne doit jamais produire un planning qui enfreint ces règles.

Exemples :
- Un enseignant ne peut pas donner deux cours simultanément.
- Une classe ne peut pas assister à deux cours simultanément.
- Une salle ne peut pas accueillir deux cours simultanément.
- L'effectif ne doit pas dépasser la capacité de la salle.
- Un enseignant doit être qualifié pour la matière.
- Un cours doit respecter son volume horaire.
- Une salle spécialisée doit être disponible pour un TP.
- Un cours ne peut pas être programmé pendant une fermeture.
- Les temps de déplacement doivent être réalisables.
- Les horaires réglementaires doivent être respectés.
B. Contraintes souples (Soft Constraints)
Optimisables
Le moteur peut les enfreindre si nécessaire, mais doit chercher à obtenir le meilleur résultat possible.

Exemples :
- Préférer les cours difficiles le matin.
- Réduire les trous dans les emplois du temps.
- Éviter les journées trop longues.
- Respecter les préférences des enseignants.
- Répartir équitablement les matières.
- Limiter les déplacements.
- Éviter les cours tardifs.
- Favoriser les journées continues.
- Éviter les changements fréquents de salles.
- Équilibrer les charges de travail.
