Règles du dossier :
- chaque chiffre et chaque citation renvoie à sa source ;
- les témoignages, les faits et le contenu commercial des éditeurs sont distingués ;
- le Maroc d'abord, puis l'Afrique francophone, les autres pays seulement pour comparaison ;
- une date sur chaque document : les prix et les avis changent vite.
