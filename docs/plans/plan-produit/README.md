## En bref

1. **Planner couvre bien la planification**, la vie de la séance et le numérique pédagogique, mais il est construit pour le supérieur.
2. **Il lui manque ce qu'une école privée achète d'abord** : notes et bulletins, frais, espace parents, arabe, Massar, et le vocabulaire du scolaire.
3. **Il n'existe pas de plan produit**, seulement des lots techniques et une stratégie commerciale qui ne se rejoignent pas. Trois ordres de priorité coexistent.
4. **Le groupe A a déjà posé deux briques décisives**, non poussées : le modèle économique par modules et le catalogue du moteur avec ses profils scolaires.
5. **Proposition** :
   - phase 0, cadrage, avec le modèle de données du scolaire ;
   - phase 1, socle de la plateforme : plusieurs écoles, registre des modules, socle neutre, profils, mise en route ;
   - en parallèle, la démonstration au directeur ;
   - phase 2, pack « École privée » ;
   - phase 3, formation professionnelle.
